# Aturan UI

Pola UI yang telah disetujui pengguna DILARANG diubah, didesain ulang, atau diganti tanpa permintaan eksplisit pengguna atau perubahan langsung oleh pengguna. Jangan melakukan perubahan visual sepihak.

Acuan kanonis: docs/ui-pattern.md dan docs/reference/penampil_arsip_ui.html. Pertahankan layout, warna, tipografi, tab horizontal, tabel, dan interaksi acuan. Revisi pertama ini menunggu persetujuan pengguna; jangan menganggapnya sudah disetujui.

Jangan membaca arsip pribadi untuk pengujian. Gunakan fixture terisolasi. Pertahankan kebijakan data sementara: idle 30 menit, batas 200 MB, cleanup sesi. Jangan commit atau push tanpa instruksi.
